# Semantic Blueprint v4：证据驱动分析、分层视图与任务进度

## 执行阶段

1. **全项目静态索引**：扫描已经建立的 AST 文件图与真实目录索引，按源包中的功能域、工程辅助区域分组；其他语言的源码文件也保留路径证据。本阶段不执行项目代码、不调用模型。
2. **候选功能域**：使用源码路径、函数名称和文件静态依赖为各功能域建立精简结构概况。这些是结构候选，不自动声称业务行为。
3. **MiMo 语义理解**：先使用一轮小型请求为候选功能域命名，再从不同功能域分层选取少量代表性 Python 代码片段，生成文件功能摘要并聚合为子功能。不会将全部源码或数据内容发送给 MiMo。未深度分析的文件保留为真实证据，而不是单独生成顶层“未分析文件”模块。
4. **分层蓝图**：投影为「功能域 → 语义子模块 → 代码文件 → 函数」；工程测试/配置/文档及结构化数据文件放在独立的工程辅助区域下。跨功能域的 LLM 关系仍标记为 `UNVERIFIED`；代码静态导入不等同于数据流。
5. **递归全局构建**：全项目首次构建后，按功能域分别执行受限的局部分析，生成各功能域下的子模块；默认最多深入分析 8 个具备至少 2 个 Python 文件的功能域，可通过 `MIMO_MAX_RECURSIVE_DOMAINS` 调整。递归/局部范围默认最多深入分析 4 个 Python 文件、总计 12000 字符，可通过 `MIMO_MAX_SCOPED_ANALYSIS_FILES` 和 `MIMO_MAX_SCOPED_TOTAL_CHARS` 调整。单文件功能域保留文件证据，不强制生成无意义的子模块。\n6. **局部重建**：在任一逻辑模块上触发重建时，仅使用该节点子树覆盖的真实文件进行分析；服务端从最新全局蓝图缓存读取当前图，重建后只替换目标节点的后代，保留祖先、兄弟模块和无关关系。结果写回全局缓存，下一次局部重建基于最新图谱。\n7. **交互展示**：双击带有子节点的逻辑模块即可进入下一层；下拉菜单可跳转到任意已构建层级；面包屑可返回上层。顶部按钮在根层执行全局递归构建，在具体模块层执行局部重建，Inspector 也提供当前节点的局部重建入口。

## MiMo / Token 限制

复制仓库根目录 `.env.example` 为 `.env`，填写 `MIMO_API_KEY`。使用兼容 OpenAI API 的接口，默认 `MIMO_BASE_URL=https://api.xiaomimimo.com/v1` 和 `MIMO_MODEL=mimo-v2.5-pro`，具体按账号授权的模型调整。

- 源代码阶段默认最多选 8 个候选 Python 文件（硬上限 12）；每文件最多 3500 字符，总量 22000 字符，可在 `.env` 调整。
- 功能域摘要使用文件路径、静态符号和计数，不传输真实数据文件内容。调用成本比原版增加一轮轻量命名请求。
- 全局结果和局部范围结果分别缓存，缓存键包含快照 ID、模型名称、提示词版本和范围文件集合；升级到 v3 后会重新构建旧缓存。\n- 局部重建请求只发送节点 ID，不会把整张图重复传回后端；服务端以本地缓存的最新逻辑图为基线。
- 分组与模块名称是候选推断；用户应依据右侧 Inspector 的源码证据核验。

## 当前技术边界

目录与函数签名是结构证据，而非运行时事实；静态输入输出不证明实际执行。动态图、反射、动态 I/O 路径和外部服务尚不能自动恢复完整调用链。对于大型项目，功能域分组由目录结构提供初始边界，复杂跨目录功能可能仍需人工调整。新增非 Python 源码节点仅提供文件存在性证据，不声称进行了 AST 解析。
原始项目只读，不执行、不导入、不编译或修改目标源码。密钥仅位于后端，不会传给浏览器。
## V4 行为约定

- 双击逻辑模块进入该模块；如果没有语义子模块，显示空层提示并可主动选择 AI 细化。单击查看 Inspector，不会产生自动收费的 LLM 调用。
- 逻辑层默认只显示业务模块和业务关系；证据层显示文件、函数与原始数据资产；混合层允许对照两类节点。
- 事实图和逻辑事实视图允许拖动。保存的仅是浏览器本地布局坐标（localStorage），不会修改项目文件、Snapshot 或连接关系；“恢复自动布局”可清除位置覆盖。
- `evidence_tools.py` 通过受限 AST 解析真实 Python 文件，查询函数签名、调用候选、常见字面量文件读写路径。工具执行器只允许读取当前作用域内的 Python 源码；不会运行或导入目标代码。
- `relation_agent.py` 先用确定性静态证据创建具体输入输出端口，再在发现相同文件路径的写入与读取时建立 `STATIC_INFERRED` 数据边。MiMo 可选地通过 OpenAI 兼容 Function Calling 调用只读工具；工具报告用于调查而非宣称运行时已发生。默认仅对一个不确定模块进行有限工具调用。
- 动态文件路径、反射、远程 API 和内存对象的数据流通常无法由 AST 字面量直接确认。无证据时不应以“确定”标记不存在的连接。
- 新建 POST `/api/snapshots/{key}/semantic-blueprint/jobs` 与 GET `.../jobs/{job_id}`，可执行全局或局部构建。前端弹窗展示后端 LangGraph 阶段完成状态及递归范围；任务状态暂存后端内存，服务重启后不保留。
- 配置 `MIMO_ENABLE_TOOL_CALLING=false` 可关闭额外 MiMo 工具调查调用，确定性 AST 关系识别仍继续执行。
